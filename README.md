# PotluckBot
This is a discord bot I made to handle the complexity of potlucks, because they're never easy

Add this bot to a server of your friends to let people
  1. Start a potluck on a specific date you put in
  2. Sign up for a valid potluck that hasn't passed yet
  3. Put down what they're bringing to a specific potluck
  4. Display what is being brought to a specific potluck

Uses the following python libraries
  * py-cord
  * supabase
  * dotenv
  * venv
